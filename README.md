# Little Lemon – Database Engineer Capstone

A database engineering project developed as the capstone project for the **Meta Database Engineer Professional Certificate**.

The project focuses on designing and implementing a MySQL database solution for the Little Lemon restaurant, together with database queries, booking functionality, reporting, data visualization, and a Python database client.

## Project Overview

The capstone brings together database engineering concepts and tools learned throughout the Meta Database Engineer Professional Certificate.

The project covers:

- Relational database design and modeling
- MySQL database implementation
- Entity Relationship (ER) modeling
- SQL queries and data manipulation
- Sales reporting
- Table booking management
- Virtual tables and JOIN operations
- Stored procedures
- Prepared statements
- Query optimization
- Data analytics and visualization
- Tableau dashboard development
- Python database client development
- Git version control

## Main Components

### 1. Database Design

The project begins with the design and implementation of the Little Lemon relational database using **MySQL Workbench**.

This includes creating an Entity Relationship (ER) model and implementing the database structure in MySQL.

### 2. Sales Reports and Database Queries

SQL queries are used to retrieve and analyze restaurant data for reporting purposes.

The project includes work with:

- JOIN operations
- Virtual tables
- Sales-related queries
- Data filtering and retrieval
- Optimized database queries

### 3. Table Booking System

The database includes functionality for managing restaurant table bookings.

The project implements SQL queries for:

- Checking available bookings
- Adding bookings
- Updating bookings
- Managing booking-related information

### 4. Stored Procedures and Prepared Statements

The project uses MySQL stored procedures and prepared statements to organize and optimize database operations.

### 5. Data Analytics and Visualization

Restaurant sales data is analyzed and visualized using **Tableau**.

The project includes an interactive dashboard for analyzing sales and profit information.

### 6. Python Database Client

A Python-based database client is included to interact with the MySQL database.

The client provides query functions for working with the database and demonstrates application-level interaction with the database solution.
